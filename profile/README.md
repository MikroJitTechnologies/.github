## About

Independent practice covering the infrastructure layer under a product: the
network it runs on, the servers it's deployed to, and the automation that
keeps it running unattended. Based in Bangkok, Thailand.

Engagements scale from a single homelab box to multi-site production
clusters — same principles at every size: self-hosted, observable, and
handed over with a runbook, not a black box.

## What We Do

| | |
|---|---|
| `network/` | Segmentation, routing, VPN, firewall policy — homelab to multi-site LAN |
| `infra/` | Kubernetes (K3s), Docker Swarm — bare metal or VPS, HA + backup strategy |
| `automation/` | CI/CD pipelines, deploy tooling, Grafana/Prometheus alerting |
| `platforms/` | Client portals, admin dashboards, and the backend services behind them |

## Approach

- **self-hosted first** — infra clients own, not rented SaaS dependency
- **built to operate** — every system ships with monitoring, backups, a runbook
- **direct engagement** — no account managers; you talk to the engineer
- **right-sized** — infra matched to actual scale, not trend-chasing
