## What we do

Independent practice covering the full stack of a running service, not just the code:

| | |
|---|---|
| 🌐 **Network design** | Segmentation, routing, VPN, firewall policy — from homelab to production LAN |
| 🖥️ **Server infrastructure** | Kubernetes, Docker Swarm, bare-metal and self-hosted deployments |
| 🔁 **Automation** | CI/CD pipelines, deploy tooling, monitoring and alerting glue |
| 🧩 **Client platforms** | Portals, dashboards, and the backend services behind them |
